# HW4: Промежуточное представление (IR) и базовые оптимизации для языка Funny

Данный модуль реализует генерацию трехадресного кода (TAC), построение графа потока управления (CFG), базовые локальные оптимизации и распределение регистров (жадная раскраска графа) для компилятора языка Funny.

## 1. Формат IR (Трехадресный код)
IR генерируется в виде списка строк. Каждая инструкция представляет собой простое действие с максимум тремя операндами.
Поддерживаются следующие типы инструкций:
- **Присваивание и математика:** `t1 = a + b`, `x = 5`, `t2 = -a`
- **Доступ к массивам:** `t1 = a[0]`, `a[t1] = 5`
- **Вызовы функций:** `t1 = call foo, a, b`
- **Метки:** `L L1` (начало базового блока)
- **Безусловный переход:** `goto L1`
- **Условный переход:** `if a > b goto L1`

## 2. Архитектура и этапы
1. **`IRGeneration`**: обходит аннотированный AST (из HW3) и генерирует линейный список инструкций.
2. **`CFGBlocks`**: разбивает линейный код на Базовые Блоки (`Block`), определяя лидеров и выстраивая связи `Successors` (куда идем) и `Predecessors` (откуда пришли).
3. **`Optimizer`**: применяет локальные оптимизации к каждому базовому блоку.
4. **`LifeInterval` и `GreedyGraph`**: анализируют живость переменных и выполняют раскраску графа конфликтов для распределения регистров.

## 3. Оптимизации и флаги
В классе `Optimizer` реализован метод `optimize(List<Block> blockList, boolean foldConst, boolean simpleAlg, boolean DCE)`. 
Оптимизации можно включать и отключать с помощью логических флагов:
- **`foldConst` (Constant Folding)**: Свёртка констант (например, `t1 = 2 + 3` → `t1 = 5`).
- **`simpleAlg` (Algebraic Simplification)**: Алгебраические упрощения (например, `x * 1` → `x`, `y + 0` → `y`, `z * 0` → `0`).
- **`DCE` (Local Dead Code Elimination)**: Удаление мертвого кода. Реализовано в виде двухпроходного алгоритма (Mark & Sweep). Переменная считается мертвой, если она записывается, но никогда не читается в блоке (при этом возвращаемые переменные функции защищены от удаления).

*Оптимизатор работает в цикле (`while(changed)`), достигая неподвижной точки: изменения, внесенные одной оптимизацией, позволяют сработать другим.*
