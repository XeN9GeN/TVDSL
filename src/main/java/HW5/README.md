# HW5: Темпоральные спецификации и проверка моделей

## Описание модели
**Модель:** Ограниченная очередь.
**Инструментальная ветка:** Spin/Promela.
**Параметры:** Ёмкость `N=2`. Пусть очередь уже защищена мьютексом.

## Структура проекта
* `queue.pml` — исходный код модели на Promela.
* `/HW5/queue_right/results` — лог успешной проверки исправной модели для каждого из свойств.
* `/HW5/queue_right/results_bug` — лог успешной проверки багованной модели для каждого из свойств.
* `README.md` — инструкция по запуску.
* `commands.txt` — команды запуска

## Спецификации (LTL)
В коде `queue.pml` заданы 5 свойств:
* **Безопасность (Safety):**
  * `S1`: `[] (count <= N)` (Нет переполнения)
  * `S2`: `[] (count >= 0)` (Нет некорректного опустошения)
  * `S3`: `[] (!err)` (Нет аварийного состояния)
* **Живость (Liveness):**
  * `L1`: ` [] ((enq1 -> <> deq1) && (enq2 -> <> deq2))` (Элемент будет извлечен или отвергнут)
  * `L2`: `[] (count > 0 -> <> (count == 0))` (Очередь в итоге опустеет)
